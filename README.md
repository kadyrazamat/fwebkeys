# fwebkeys
Жоба туралы қысқаша PKeys Finance — бұл пайдаланушыларға өз кірістері мен шығындарын бақылауға, айлық бюджетті тиімді жоспарлауға және импульсивті (ойланмай жасалатын) сатып алулардан сақтануға көмектесетін заманауи веб-қосымша. Жоба жастар мен қаржысын саналы түрде басқысы келетін әрбір адамға арналған ыңғайлы құрал ретінде жасалған.
